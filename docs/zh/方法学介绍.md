# 方法学介绍

## 概述

本工作构建并验证一个面向中医「舌、面、脉」三模态的肺癌识别与可解释性分析框架。整个研究遵循「数据预处理 → 锁定 SVM 三模态融合 → SHAP 解释 → Drop-One-Modality 功能消融 → Lasso L1 代理蒸馏」的递进式分析路径，构成**三层证据链**：

1. **SHAP 边际重要性**（KernelExplainer）：每个特征对 SVM 决策的边际贡献；
2. **Drop-One 功能重要性**：移除整个模态后 AUC 的下降幅度；
3. **Lasso L1 稀疏代理**：用线性模型逼近 SVM 决策，提取核心可解读特征。

三层证据互补，正式解答论文记录的 **"Pulse Paradox"**：脉诊特征在 SHAP 排名中靠前，但功能上与面/舌冗余。

---

## 1. 数据与预处理

### 1.1 数据来源与样本
- **数据文件**：`去除重复人员异常值处理后-Lasso后舌脉面.csv`
- 经过去重、异常值剔除与 Lasso 特征筛选后的最终分析数据集；
- **样本规模**：N = 1,580（阳性 771 / 48.8%，阴性 809），类别相对均衡；
- **特征维度**：共 121 个特征。

### 1.2 模态归属划分

| 模态 (Modality) | 特征前缀 | 特征数 |
|:---:|:---|:---:|
| 面 (Face) | `color`, `lipcolor`, `wholecolor`, `GLCM` | 83 |
| 舌 (Tongue) | `TB`, `TC`, `Per` | 28 |
| 脉 (Pulse) | `h`, `w`, `t` | 10 |

**前缀匹配顺序**：Face → Tongue → Pulse。该顺序确保 `wholecolor-*`（以 `w` 开头）不会被误匹配到 Pulse 的 `w` 前缀。

### 1.3 预处理流水线 (Preprocessing Pipeline)
所有模型统一使用 `sklearn.pipeline.Pipeline` 封装：
1. **缺失值填补**：`SimpleImputer(strategy='median')` —— 中位数填补，对偏态分布稳健；
2. **标准化**：`StandardScaler()` —— 均值 0、方差 1 标准化；
3. **分类器**：接入锁定的 SVM。

### 1.4 数据划分
- `train_test_split(test_size=0.2, random_state=42, stratify=y)` —— **分层抽样**；
- 训练集 N=1,264 用于 5 折 CV 与模型拟合，测试集 N=316 用于最终性能评估，**严格避免数据泄漏**。

## 2. 多模态融合建模：锁定 SVM（与论文一致）

### 2.1 模型选择
论文已在 9 种候选算法（XGBoost / LightGBM / 随机森林 / 逻辑回归 / 神经网络 / SVM / KNN / GBDT / MLP）中通过 10 折 CV 比较，最终选定 **SVM** 作为锁定最佳模型。本分析沿用该锁定模型，确保所有可解释性结论指向同一个被论文报告的黑箱。

### 2.2 SVM 精确配置
```python
from sklearn.svm import SVC
SVC(C=1.0, kernel='rbf', gamma='scale',
    class_weight='balanced', probability=True,
    random_state=42)
```

| 超参数 | 值 | 含义 |
|:---|:---|:---|
| `C` | 1.0 | 正则强度（较大 = 较少正则） |
| `kernel` | `'rbf'` | 径向基核函数 |
| `gamma` | `'scale'` | 核宽度 = 1 / (n_features × X.var()) |
| `class_weight` | `'balanced'` | 类别权重自动反比于频率 |
| `probability` | `True` | 启用 Platt 缩放，输出概率 |

### 2.3 性能评估方法
- **5 折分层交叉验证**：在训练集上计算 CV AUC 与标准差；
- **Test AUC**：独立测试集上的最终泛化性能；
- **95% CI**：**DeLong 法** 解析计算 AUC 方差（基于 Mann-Whitney 统计量的渐进正态分布）；
- **DeLong z 检验**：用于模型间 AUC 比较，多重组间比较采用 **Bonferroni 校正**。

### 2.4 基线性能（与本分析复现一致）
- CV AUC = **0.9486 ± 0.0095**（论文报告 0.951）；
- Test AUC = **0.9257**（95% CI: 0.898–0.954；论文报告 0.926）；
- 完全对齐论文 SHAP 节的"locked SVM"基准。

## 3. SHAP 可解释性分析（KernelExplainer）

### 3.1 为什么用 KernelExplainer 而非 TreeExplainer
SVM（RBF 核）不是树模型，无法使用 `TreeExplainer`。论文采用 **`KernelExplainer`**：通过 Kernel SHAP 的局部加权线性逼近，对任意黑箱（包括 SVM）计算 Shapley 值，理论基础为博弈论的 Shapley 值公理。

### 3.2 背景数据 (Background Distribution)
SHAP 值是相对于某个**参考分布**的边际贡献。论文采用 **k-means 聚类原型** 作为背景，将训练集压缩到 K 个聚类中心，既保证 SHAP 公理成立，又显著降低计算开销。

```python
background = shap.kmeans(X_proc, k=50)  # 论文 k=100，本分析减到 50 提速
explainer = shap.KernelExplainer(
    lambda arr: svm.predict_proba(arr)[:, 1],   # 返回 P(class=1)
    background
)
```

### 3.3 解释样本 (Explanation Set)
从训练集随机抽取 **200 个样本** 用于计算 SHAP 值（KernelExplainer 时间复杂度 O(N × K × P)，200 × 50 × 121 ≈ 1.2M 次 SVM 推理，约 30 分钟）。

### 3.4 模态级 SHAP 聚合
对每个模态 $m$，提供两种互补视图：

| 聚合方式 | 公式 | 含义 |
|:---|:---|:---|
| **Sum\|SHAP\|** | $\sum_{j \in m} \mathbb{E}[\|\phi_j\|]$ | 模态总体贡献（受特征数影响） |
| **Mean\|SHAP\|** | $\frac{1}{\|m\|} \sum_{j \in m} \mathbb{E}[\|\phi_j\|]$ | 单特征平均贡献密度（消除特征数差异） |

> **关键洞见**：脉诊特征数最少（10 个）但 Mean\|SHAP\| 最高，反映其单变量信息密度高；面诊 Sum\|SHAP\| 占比最大，反映其总体贡献最大。两者互为补充。

### 3.5 可视化
- **Top-20 SHAP Beeswarm plot**：样本级 SHAP 分布，反映方向性与大小；
- **Sum/Mean |SHAP| 双视图柱状图**：模态聚合对比。

## 4. Drop-One-Modality 功能消融分析

### 4.1 动机
SHAP 反映的是**边际重要性 (marginal importance)**：当某模态的信息被其它模态冗余覆盖时，其 SHAP 值会被低估；反之，单独信息密集的特征也可能在联合模型中功能冗余。为量化每个模态的**唯一功能贡献 (unique functional contribution)**，我们采用 Drop-One-Modality 消融实验。

### 4.2 方法
依次移除一个模态，**重新训练完整的 SVM**（保持其余预处理与超参完全一致），记录测试集 AUC 下降：

$$
\Delta \text{AUC}_m = \text{AUC}_{\text{full}} - \text{AUC}_{-m}
$$

为避免单次 split 的随机性，采用 **1,000 次分层 Bootstrap** 计算 ΔAUC 的 95% 置信区间。

### 4.3 相对增量价值 (Incremental Value %)
$$
\text{IV}_m = \frac{\Delta \text{AUC}_m}{\sum_k \Delta \text{AUC}_k} \times 100\%
$$

IV% 衡量该模态在三模态总和中的功能占比，是临床转化中评估"值不值得纳入"的关键指标。

### 4.4 为什么 Drop-One 是模态贡献的"金标准"
- 直接量化**功能损失**（AUC 下降），而非依赖模型内部归因（SHAP/注意力权重）；
- 包含**所有非线性交互**（SVM 重训后自动调整决策边界）；
- 提供**置信区间**支持统计推断。

## 5. Lasso L1 代理模型蒸馏

### 5.1 动机
SVM（RBF 核）虽性能优异，但黑箱决策机制难以满足临床可解释性需求。我们引入 **Lasso L1 代理模型 (surrogate model)** 对其决策函数进行稀疏线性近似。

### 5.2 蒸馏目标 (Distillation Target)
不直接拟合原始标签 $y$，而拟合 SVM 在训练集上的**预测概率** $\hat{p}$：

$$
\hat{p} = f_{\text{SVM}}(X) \approx \beta_0 + \sum_j \beta_j X_j
$$

使用 L1 正则化的 Lasso 回归，通过调节正则强度 $\alpha$ 控制稀疏度。

> **为什么蒸馏 SVM 概率而非原始标签**：拟合概率让 Lasso 学到的是 **SVM 的决策函数**，而非一个独立的简单分类器——这样得到的稀疏特征清单才能真正"解释"论文锁定的黑箱。

### 5.3 正则路径扫描 (Regularization Path)
扫描 $\alpha \in \{0.001, 0.002, 0.005, 0.01, 0.02, 0.05, 0.1\}$，绘制「特征数 ↔ Surrogate AUC」与「特征数 ↔ 保真度 (correlation with SVM)」曲线。

### 5.4 拐点判据 (Knee Criterion)
在满足 **Surrogate AUC ≥ 95% × SVM AUC** 的所有配置中，选择**特征数最少**者作为拐点。

### 5.5 稳定性选择 (Stability Selection)
为抑制单次 Lasso 拟合的随机性，执行 **Bootstrap 50 次** 的稳定性选择：

1. 每次按类别比例有放回重采样；
2. 拟合 Lasso，记录被选中的特征；
3. 统计每个特征被选中的**频率 (selection frequency)**；
4. 仅保留 **频率 ≥ 80%** 的特征作为稳定核心特征。

### 5.6 最终输出
- 每个核心特征的**符号化系数**（正号 = 风险增、负号 = 风险减）；
- **模态归属**（面 / 舌 / 脉）；
- **选择频率**（稳定性指标）。

## 6. 统计分析

| 分析目的 | 方法 |
|:---|:---|
| AUC 95% CI | **DeLong 法**（基于 Mann-Whitney 统计量的解析方差） |
| ΔAUC 95% CI | **分层 Bootstrap**（1,000 次重采样，按类别比例有放回） |
| 模型间 AUC 比较 | 基于 DeLong 协方差的 **z 检验**，多重比较用 **Bonferroni 校正** |
| 模型稳定性 | **5 折分层 CV ± std** |
| 代理模型稳定性 | **Stability Selection**（50 次 Bootstrap + 80% 频率阈值） |
| 代理保真度 | **Pearson 相关**（Lasso 输出 vs SVM predict_proba） |

## 9. 方法学优势与局限

### 优势
1. **三层证据互补**：SHAP 边际 / Drop-One 功能 / Lasso 稀疏，覆盖模型归因的不同维度；
2. **锁定 SVM 一致性**：所有分析指向同一个论文报告的黑箱，避免"分析对象与论文模型脱节"的方法学陷阱；
3. **Drop-One + Bootstrap CI**：直接量化功能损失并提供统计置信度，是模态贡献的"金标准"；
4. **稳定性选择**：通过 Bootstrap 抑制 Lasso 系数随机性，保证特征清单的鲁棒性；
5. **严格统计**：DeLong 95% CI、分层 Bootstrap、Bonferroni 校正，满足 SCI 投稿统计要求。

### 局限
1. **样本规模**：1,580 例相对中小样本，外部验证已由论文报告（AUC 0.939）；
2. **特征级融合**：未与决策级融合 / 注意力级融合对比；
3. **静态特征**：未纳入时序脉诊信号，脉诊信息表达受限；
4. **Lasso 线性近似局限**：对 SVM 非线性交互的捕捉有限，可能导致部分高阶交互特征被低估；后续可探索 GAM、RuleFit 或 Agent-based surrogate。

## 10. 核心结论一句话概括

> 通过 SHAP 边际重要性、Drop-One 功能消融、Lasso 稀疏代理三层证据，本研究正式解答了论文记录的 **"Pulse Paradox"**：脉诊特征（尤其 `h1-t1`）在单变量层面信息密集、进入 Lasso 稀疏代理，但移除整个脉诊模态后 SVM AUC 损失最小——说明其信号在联合模型中已被面/舌特征**部分冗余覆盖**。**面诊是主导模态，舌诊提供补充，脉诊提供高密度但冗余的信息**，三者构成互补的多模态识别体系。
