# CI 工具链说明（0803 版）

本目录下三个 `0803-CI-*` 脚本共同构成论文 **Table 2 – Table 7 + 补充材料** 的全部 95% 置信区间（CI）输出工具链。
全部基于相同的随机种子 `RANDOM_SEED = 42`、相同的锁定 SVM 超参（`C=1.0, gamma='scale', kernel='rbf', class_weight='balanced'`），保证可复现、口径一致。

---

## 1. 三个脚本的依赖关系

```
0803-CI-主-Table2_3.py                  ← 主模块（基础工具库 + Table 2/3 主流程）
        ↑ importlib.util 加载
        ├── 0803-CI-补充-风险分层.py      ← 补充材料：风险分层 LC 比例 CI
        └── 0803-CI-补充-Table4_7.py      ← 补充材料：Table 4–7（独立模态 CSV 版）
```

- **主模块**（`0803-CI-主-Table2_3.py`）= 工具库 + Table 2/3 主流程。其他两个脚本通过 `importlib.util.spec_from_file_location` 加载它的 `load_dataset` / `harmonize_columns_to_dev` / `wilson_ci` / `cv_with_full_ci` / `evaluate_on_set` 等函数。
- 因此 **改名时必须同步修改两个补充脚本里写死的绝对路径**（搜 `0803-CI-主-Table2_3.py` 即可定位）。

## 2. 各 Table 的具体含义

| Table | 内容 | 数据来源 | CI 方法学 | 由哪个脚本输出 |
|---|---|---|---|---|
| **Table 2** | 多模态（舌+面+脉 121 特征）9 模型 10 折分层 CV | `去除重复人员异常值处理后-Lasso后舌脉面.csv` | AUC: DeLong；其他指标: 1000 次 percentile bootstrap；折均值: `mean ± t(0.975, 9) × SE` | **主模块** |
| **Table 3** | 多模态 **SVM 锁定超参** 内部测试 + 外部验证 | 同上 + `两组舌面脉...外部验证.csv` | AUC: DeLong；其他: 1000 次 bootstrap | **主模块** |
| **Table 4** | **单模态**（舌 / 面 / 脉）9 模型 CV | 用户预先切好的 3 份单模态开发 CSV（舌 2300 / 面 2299 / 脉 1759） | 同 Table 2 | **补充-Table4_7** |
| **Table 5** | **单模态最优模型**（舌 XGBoost / 面 XGBoost / 脉 GBDT）内部 + 外部 | 同 Table 4 + 3 份单模态外部 CSV | 同 Table 3 | **补充-Table4_7** |
| **Table 6** | **年龄性别 1:1 PSM 匹配队列** 9 模型 CV | `PSM-异常值处理后-舌脉面-0113-模型开发训练.csv`（n=598） | 同 Table 2 | **补充-Table4_7** |
| **Table 7** | **匹配队列 SVM 锁定超参** 内部 + 外部 | 同 Table 6 + `PSM-两组-舌面脉-外部测试集0113-Lasso后-外部验证.csv`（n=182） | 同 Table 3 | **补充-Table4_7** |
| **Supp（风险分层）** | 按 0.40 / 0.80 阈值分 Low / Intermediate / High 三层，统计 LC 阳性比例 + Wilson 95% CI + High/Low 比值 + delta-method CI | 同 Table 3 | Wilson score interval + delta method（log 空间） | **补充-风险分层** |

### 关于"主模块是否只输出 Table 2-3"

- **代码层面**：主模块内部其实定义了 Table 2 – Table 7 的全部函数（`run_table2_*` ~ `run_table7_*`），但你得有一份含 `age` / `sex` 列的开发 CSV 才能跑 Table 6/7 的 PSM；Table 4/5 的单模态需要从主 CSV 现场按前缀过滤。
- **实际工作流**：Table 4-7 通常用 **`补充-Table4_7`（独立模态 CSV 版）** 直接跑——因为它读的是你预先切好的、样本量明确的 8 个 CSV（舌 2300 / 面 2299 / 脉 1759 / 匹配 598+182），口径更清晰、可控。
- 所以在日常使用上，**主模块 ≈ Table 2-3 输出器**，没有问题。

## 4. 外部验证列名对齐（`/` ↔ `-`）

历史上开发 CSV 用 `h4-h1` 连字符记法，外部 CSV 用 `h4/h1` 斜杠记法 → 6 个脉象比值特征对不齐，被中位数填补吞掉，实际只用 115/121 特征，external AUC = 0.939（论文原口径）。

**2026-08-03 修复后**：外部 CSV 改为与开发一致的 `/` 记法，6 个特征被正确加载，全部 121 特征参与 → external AUC ≈ 0.954。

主模块的 `harmonize_columns_to_dev()` 仍保留两种模式：

| 模式 | 标志 | 行为 | AUC |
|---|---|---|---|
| 修复版（默认） | 不加任何参数 | 全部 121 特征 | ≈ 0.954 |
| Legacy bug 复现 | `--legacy-nan-bug` | 6 个脉象比值特征强制 NaN | ≈ 0.939（与论文一致） |

**风险分层脚本默认走修复版**——只要不加 `--legacy-nan-bug` 即可。

## 5. 运行方式

每个脚本都支持 `python <脚本名> --help` 查看参数。

```bash
# Table 2-3 主流程（多模态 9 模型 + SVM 锁定 内/外）
python "0803-CI-主-Table2_3.py"

# Table 4-7 补充（独立模态 CSV 版）
python "0803-CI-补充-Table4_7.py"

# 补充材料：风险分层 CI
python "0803-CI-补充-风险分层.py" --out <输出目录>
```

输出默认写到各自指定的 `out_dir`；补充-风险分层的 `--out` 默认值指向旧的 `石老师npj投稿` 目录，**建议显式指定** `--out` 到当前项目的 `CI汇总备查/` 子目录。

## 6. 改名/搬家时的注意事项

如果再次重命名三个脚本：

1. 三个文件名都要同步更新本文档第 1 节的依赖图。
2. **必改**：两个补充脚本里 `importlib.util.spec_from_file_location` 第二个参数（绝对路径），搜 `0803-CI-主-Table2_3.py` 即可定位。
3. **必改**：本 README 文件名 `0803-CI工具链-说明.md` 里的日期前缀（如有需要）。
4. 主模块里 `DATA_PATH` / `EXTERNAL_PATH` 写死了 CSV 绝对路径（行 60-61），如果数据 CSV 改名也要同步。
