# 三层证据链整合分析说明

**汇报摘要**：论文用 SHAP 方法分析模型时发现一个矛盾现象——脉诊在单变量层面排名第一，但单独作为模态使用时性能最弱。为弄清脉诊到底重不重要，本研究在 SHAP 分析之外补充了两组分析：**逐模态删除测试**（删掉某个模态看模型掉多少）和**稀疏代理模型**（用最少特征能否复现模型性能），与 SHAP 构成三层证据链。

**三层证据合流的最终结论**：脉诊**单个特征携带的信号确实最强**（每个特征平均推力是面诊的 1.86 倍、在 22 个"反复训练都跳不掉"的核心特征中超比例入选），**但删掉整个脉诊后模型性能几乎不掉**（AUC 仅降 0.016、统计上不显著，95% 置信区间跨越 0），说明脉诊信号在联合模型中已被面诊和舌诊冗余覆盖——**既不是脉诊没信息，也不是临床上可有可无**，准确说法是"单特征信息效率高、跨模态冗余"，对应论文 §168 的核心论断。

同时发现，**仅用 22 个核心特征（占原始 121 个的 18.2%）就能保留 95.8% 的模型性能**，为未来床旁简化工具和前瞻验证提供了最小特征清单。

## 0. 名词速查（先看这个再看正文）

| 术语 | 通俗解释 |
|:---|:---|
| **SVM 黑箱** | 论文锁定的预测模型。说"黑箱"是因为它内部计算复杂，肉眼读不出"它到底看中哪些特征"。 |
| **SHAP 值** | 把模型的预测结果"反推"到每个输入特征的贡献。正值=推高肺癌预测，负值=推低。 |
| **KernelExplainer** | SHAP 的一种算法，能对 SVM 这种黑箱算 SHAP 值。 |
| **Sum \|SHAP\| %** | 一个模态所有特征的 SHAP 绝对值加起来，占三个模态总和的比例。受特征数影响——特征越多、加和越大。 |
| **Mean \|SHAP\|** | 一个模态平均每个特征的 SHAP 绝对值。**消除特征数差异**后的"单特征密度"。 |
| **Drop-One-Modality** | 把整个模态（如脉诊 10 个特征）全删掉，SVM 重训，看 AUC 掉多少。 |
| **ΔAUC** | 删模态前后的 AUC 差值 = AUC_full − AUC_drop。差值越大、说明这个模态越不可替代。 |
| **95% CI（置信区间）** | 真实值有 95% 概率落在这个范围。**CI 跨越 0** = 统计上不能排除"实际效果为零"。 |
| **DeLong CI** | AUC 专用的解析置信区间算法（论文用）。 |
| **Bootstrap CI** | 有放回重采样 1000 次，从结果分布取 2.5%–97.5% 作为 95% CI。 |
| **IV%（增量价值%）** | 三个模态的 ΔAUC 归一化到 100% 的描述占比，**不是因果贡献比例**。 |
| **Lasso 代理（Surrogate）** | 用一个简单的线性模型（Lasso）去模仿 SVM 黑箱的输出。"代理"="替身"。 |
| **L1 正则（Lasso）** | 一种强制"用更少特征"的约束机制。α 越大、保留的特征越少。 |
| **拐点 α=0.02** | "用最少特征仍能达到 SVM 95% 性能"的最优点（α=0.02 时保留 34 个特征）。 |
| **Stability Selection（稳定性选择）** | 反复有放回重采样训练 50 次，统计每个特征被选中的频率。 |
| **稳定代理特征** | **50 次 bootstrap 中被 Lasso 选中 ≥ 80% 的特征**——可以理解为"反复训练都跳不掉的核心变量"，是 SVM 黑箱决策中最稳定的少数关键输入。本研究共 22 个。 |
| **保真度（Pearson r）** | 代理模型输出和原 SVM 输出的相关系数。r=1 完美模仿，r=0.83 说明代理只能模仿 SVM 的 83%。 |
| **Pulse Paradox（脉诊悖论）** | 论文 SHAP 节观察到的现象：脉诊单模态最弱（AUC 0.827），但 SHAP 单变量排名最前（Top-3 全是脉诊）。 |
| **Kernel SHAP 背景** | SHAP 值需要一个"参考分布"做对比。本研究用 k-means 把训练集聚成 50 个原型作为背景。 |
| **RBF 核** | SVM 用的径向基核函数，能拟合非线性决策边界。 |

## 1. 为什么要做这三层分析

论文 SHAP 节（manuscript §127–131, Fig 9）记录了一个表面矛盾：

- 单模态基准：**Face 0.917 > Tongue 0.843 > Pulse 0.827**（Table 4）
- SHAP 单变量 Top-3：**h1/t1、h4/h1、t1/t —— 全是脉诊**（Fig 9A）
- SHAP 模态总体贡献：Face 65.8% ≫ Tongue 19.5% > Pulse 14.7%（Fig 11C）

也就是说，**脉诊单模态最弱，但单特征 SHAP 排名最高**。这就是 "Pulse Paradox"。

SHAP 是**条件归因**（在其他特征已经存在时，单个特征的边际推力），它无法回答：

- 把脉诊整个删了，模型会跌多少？
- 脉诊的高 SHAP 是真不可替代，还是被面/舌冗余覆盖？
- 能不能找到一组最小特征，线性近似就能复现 SVM 的大部分性能？

要回答这些问题，需要补充两层分析：**Drop-One（功能层）** 和 **Lasso 代理（压缩层）**。

## 2. 三层方法对比

| 层 | 工具 | 度量 | 回答的问题 | 局限 |
|:---|:---|:---|:---|:---|
| **L1 边际归因** | KernelExplainer SHAP | mean\|φ\|、Σ\|φ\| | 拟合好的 SVM 里，每个特征推力多大？ | 条件于其他特征，不等于删了会怎样 |
| **L2 功能消融** | Drop-One-Modality + 1000×分层 bootstrap | ΔAUC + 95% CI | 把整个模态删掉、SVM 重训，真实损失多少？ | 模态粒度，不能归因到单特征 |
| **L3 稀疏代理** | Lasso L1 + Stability Selection | 系数 + 选择频率 | 用最少多少特征能线性近似 SVM？ | 线性近似，保真度有上限 |

三层不可互替：L1 描述决策规则，L2 描述临床不可替代性，L3 描述信息压缩极限。

## 3. 锁定 SVM 基线（三层共同对象）

```python
SVC(C=1.0, kernel='rbf', gamma='scale',
    class_weight='balanced', probability=True, random_state=42)
```

- 数据：N=1,580（阳 771/48.8%），121 维（Face 83 + Tongue 28 + Pulse 10）
- 分割：分层 80/20（训练 1,264 / 测试 316）
- 性能（与论文 Table 3 一致）：
  - CV AUC（10 折，论文）：**0.951 (0.939–0.962)**
  - 内部测试 AUC：**0.9257 (0.898–0.954)**
  - 外部 AUC：**0.939 (0.924–0.954)**

三层分析都针对这同一个锁定的 SVM。

## 4. 第一层：SHAP 边际归因

**方法**：KernelExplainer（k-means 50 背景、200 解释样本、概率空间）。提供两个互补视图：

- **Sum |SHAP|%**：模态总体贡献（受特征数影响）
- **Mean |SHAP|**：单特征密度（消除特征数差异）

**结果**：

| 模态 | 特征数 | Sum \|SHAP\| % | Mean \|SHAP\| |
|:---|:---:|:---:|:---:|
| Face | 83 | **65.8%** | 0.0126 |
| Tongue | 28 | 19.5% | 0.0111 |
| Pulse | 10 | 14.7% | **0.0234** |

Top-10 特征里，前三名都是脉诊比值（h1-t1、h4-h1、w1-t），与论文 Fig 9 一致。

**判读**：面诊总体贡献主导，但脉诊单特征密度最高（是面诊的 1.86 倍）。两个指标给出不同答案——脉诊"少而集中"。

---

## 5. 第二层：Drop-One-Modality 功能消融

**方法**：依次移除 Face / Tongue / Pulse，**用相同 SVM 重训**，计算 ΔAUC = AUC_full − AUC_drop；1000 次分层 bootstrap 给 95% CI。

**结果**：

| 移除模态 | 重训后 Test AUC | 95% DeLong CI | **ΔAUC** | **95% Bootstrap CI** | IV% |
|:---|:---:|:---:|:---:|:---:|:---:|
| Face | 0.8383 | [0.7950, 0.8816] | **+0.0874** | [+0.0494, +0.1287] | 70.0% |
| Tongue | 0.9046 | [0.8724, 0.9367] | +0.0211 | [+0.0044, +0.0387] | 16.9% |
| Pulse | 0.9093 | [0.8788, 0.9398] | **+0.0164** | [**−0.0006**, +0.0345] | 13.1% |

**判读**：

- **Face**：AUC 跌 0.087，CI 完全 > 0，统计显著 —— **绝对主导模态**
- **Tongue**：AUC 跌 0.021，CI 不含 0 —— **重要补充**
- **Pulse**：AUC 仅跌 0.016，**CI 下限 −0.0006 跨越 0** —— 统计上不能拒绝"零增量"

注：IV%（70/16.9/13.1%）只是描述性归一化，**不是统计或因果贡献比例**（manuscript §57, §129）。

## 6. 第三层：Lasso L1 稀疏代理

**方法**：

1. 在 SVM 训练集**预测概率**（非标签）上拟合 Lasso → 学到 SVM 黑箱的稀疏线性近似
2. 扫描 α ∈ {0.001, 0.002, 0.005, 0.01, 0.02, 0.05, 0.1}
3. 拐点判据：最少特征数 且 Surrogate AUC ≥ 95% × SVM AUC
4. Stability Selection：50 次 bootstrap + 80% 频率阈值

**正则路径拐点**：α=0.02 → 34 个非零特征，Surrogate AUC = **0.8969**，与 SVM 概率的 Pearson r = **0.8348**。

**最终稳定核心**：**22 个特征**（Face 12 / Tongue 4 / Pulse 6），AUC = **0.8872** vs SVM 0.9257，绝对差 0.0385。

**Top-7 稳定核心特征**：

| 特征 | 模态 | 系数 | 选择频率 |
|:---|:---|:---:|:---:|
| color-G-3 | Face | +0.094 | 100% |
| Per-all | Tongue | −0.088 | 100% |
| **h1-t1** | Pulse | +0.084 | 100% |
| wholecolor-Cr | Face | +0.070 | 100% |
| color-Cb-1 | Face | −0.068 | 100% |
| GLCM-asm_3 | Face | −0.062 | 100% |
| h4-h1 | Pulse | −0.061 | 100% |

**判读**：

- 脉诊占原始 10/121 = 8.3% 特征份额，却贡献 6/22 = 27.3% 稳定代理特征 → **超份额入选**，与 L1 单特征密度高一致
- 但代理保真度封顶 r ≈ 0.83 < 0.90 → SVM 非线性决策**不能被线性代理完全恢复**
- 22 特征保留 SVM 95.8% 的 AUC，但 manuscript §175 强调这只是 "explanatory approximation"，不替代外部验证过的 SVM

## 7. Pulse Paradox 的最终解答

### 7.1 先说清"密度"是什么意思

SHAP 值衡量每个特征对模型预测的"推力"大小。一个模态里有很多特征，看总体还是看人均，答案不一样：

- **总体贡献（Sum |SHAP|%）**：模态所有特征的推力加起来占三个模态总和的比例。
  - 面诊：83 个特征加起来 = **65.8%**
  - 脉诊：10 个特征加起来 = **14.7%**
- **单特征密度（Mean |SHAP|）**：每个特征平均分到的推力。
  - 脉诊：14.7% ÷ 10 ≈ **0.0234/特征**
  - 面诊：65.8% ÷ 83 ≈ **0.0126/特征**
  - 舌诊：19.5% ÷ 28 ≈ **0.0111/特征**

**类比**：A 公司 100 个员工总营收 100 万、人均 1 万；B 公司 2 个员工总营收 50 万、人均 25 万。A 总量大，B 人均高。脉诊就是 B——**总量小但每个特征都"重"**。

### 7.2 三层证据对脉诊的具体判断

| 层 | 关键数字 | 白话判断 |
|:---|:---|:---|
| **L1 SHAP 单特征密度** | 脉诊 0.0234 > 面诊 0.0126 > 舌诊 0.0111（脉诊是面诊的 1.86 倍） | 每个脉诊特征对模型推力最强 |
| **L1 SHAP 模态总体贡献** | 面诊 65.8% > 舌诊 19.5% > 脉诊 14.7% | 但脉诊总特征只有 10 个，加起来总量垫底 |
| **L2 Drop-One ΔAUC** | 删面诊 0.0874 / 删舌诊 0.0211 / **删脉诊 0.0164（CI −0.0006 ~ +0.0345，跨 0）** | 删脉诊 AUC 几乎不掉，统计上不能说脉诊有独立功能贡献 |
| **L3 Lasso 稳定代理特征** | 22 个稳定特征中脉诊占 6 个（27.3%），而脉诊原始份额只有 10/121=8.3% | 但在"反复训练都跳不掉"的核心变量里，脉诊超份额入选 |

### 7.3 三个层次的一致与分歧

- **L1 高密度 + L3 超份额入选**（两层一致）→ 脉诊的单个特征**确实有信息**
- **L2 ΔAUC ≈ 0 且 CI 跨 0**（与上面分歧）→ 但删了脉诊模型几乎不掉性能

为什么分歧？因为**面诊和舌诊已经"吸收"了脉诊的相同信号**。生理上，心血管/代谢状态会同时反映在面色改变和脉波形态上——模型看到面色时就已经间接拿到了脉诊携带的大部分信息，所以再删脉诊不疼。

### 7.4 三句话最终结论

1. **脉诊的单特征确实携带强信号**（SHAP 密度最高、Lasso 超份额入选都证实）
2. **但删了整个脉诊模型几乎不掉性能**（面/舌已经把脉诊的信号冗余覆盖了）
3. **所以 SHAP 排名 ≠ 临床不可替代 ≠ 因果生理**——模型用脉诊做决策，不代表脉诊在临床上不可或缺，更不能直接说"脉诊异常导致肺癌"

这正是论文 §168 的核心结论：**单特征信息效率高、但跨模态冗余；既不是脉诊没信息，也不是脉诊在临床上可有可无**。

### 8.2 SHAP 节 → 三层证据节

SHAP 节只回答"模型内部怎么决策"。三层证据节回答三个递进问题：

1. "Top-3 SHAP 都是脉诊，但脉诊删了真的会掉性能吗？" → Face ΔAUC 0.087（最痛），Pulse ΔAUC 0.016 且 CI 跨 0
2. "脉诊总体贡献低（14.7%）是因为没用，还是因为特征少？" → Mean|SHAP| 0.0234 揭示是后者
3. "能不能用更少特征近似 SVM？" → 22 个稳定特征 AUC 0.887，保真度封顶 0.83

### 8.3 三层证据节 → 个例展示节（Fig 14）

Fig 14 是 27 例外部分层（low/intermediate/high 各 9 例）的舌像/面像/脉波原始信号。它的作用**不是再添一层定量证据**，而是：

1. **可视化了模型实际看到什么**——把抽象的 SHAP 值/系数落到具体病人的舌面色/纹理/脉波上
2. **目视印证三层结论**——高分案例可见舌质/面色异常与脉波形态改变，与"面诊主导、脉诊冗余但信息密集"的判断在视觉上一致
3. **提示脉诊冗余的生理直觉来源**——同一受试者的面色与脉波改变常常同步出现（心血管/代谢状态在多面反映），与 L2 检测到的"删脉诊 AUC 不掉"在机制上呼应
4. **承接三层定量证据，下接 prototype 与前瞻验证**

manuscript §154–157 明确把 Fig 14 定位为 "descriptive montage"，不参与性能估计或阈值选择。

## 9. 这么做的整体目的

把 SHAP 之后的可解释性内容整合看，根本目的有四：

1. **方法论自洽**——单独 SHAP 会被审稿人质疑"归因≠因果、归因≠不可替代"。三层叠加把"模型归因 / 模态功能 / 信息压缩"分别量化，避免单层归因被误读。

2. **解答 Pulse Paradox**——脉诊既是 TCM 最具特色的一环，也是 SHAP 排名最靠前的特征族。L1+L2+L3 的"部分一致 + 部分分歧"是最诚实的答案（§168）。

3. **给出可操作的特征清单**——L3 的 22 个稳定特征可作为床旁简化版的输入（18.2% 特征 → AUC 仅降 0.039），也是未来前瞻验证的最小特征集。

4. **为 SHAP 解释力划定边界**——L3 保真度封顶 r ≈ 0.83 < 0.90，证明 SVM 仍有线性代理无法捕捉的非线性成分，保护论文不夸大 SHAP 解释力，并指引未来工作（GAM / RuleFit / 注意力级代理）。
