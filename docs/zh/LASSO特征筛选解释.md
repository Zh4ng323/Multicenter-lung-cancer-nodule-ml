● 用考试类比解释

  想象老师出期末考试：

  正确的做法（无泄露）：
  - 老师从题库里出题，学生做练习题（训练集），然后考试（测试集）
  - 学生没见过考试题，考出的分数是真实水平

  当前的做法（有泄露）：
  - 老师先把所有题目（包括考试题）拿出来，分析"哪些题最能把好学生和差学生分开"——这就是 LASSO 做的事，它从所有数据中找出最有区分力的特征
  - 然后用选出的这些题组成考试
  - 结果学生考前就已经知道"考试肯定考这几类题"，虽然没见过具体题目，但复习方向完全精准
  - 考出来的分数自然偏高——这就是 AUC=0.950 的来源

  一句话总结

  ▎ LASSO 在全数据上选特征 = 提前偷看了考试范围。

  模型在测试集上表现好，不是因为模型真的厉害，而是因为特征选择阶段已经把测试集的信息"泄露"给了模型——告诉它"看这几个特征就够了"。

  修复很简单

  先划分训练集和测试集，只用训练集做 LASSO，测试集完全不看。这样考出来的才是真实成绩。
